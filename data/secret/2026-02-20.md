# 做菜的主要方法

🔥 빠른 고온 조리

1.  **爆 (bào)** → 아주 센 불에서 짧은 시간에 빠르게 볶는 방법 (강한 화력으로 재료의 향을 순간적으로 살림)

2.  **炒 (chǎo)** → 기름을 두르고 재료를 저어가며 볶는 가장 일반적인 방법

3.  **溜 (liū)** → 한 번 튀기거나 볶은 뒤 소스를 넣어 빠르게 다시 조리하는 방법

🍳 기름을 사용하는 조리

4.  **炸 (zhá)** → 기름에 튀기는 방법 (깊은 기름 사용)

5.  **煎 (jiān)** → 적은 기름으로 지지듯이 굽는 방법

🍲 천천히 익히는 조리

6.  **炖 (dùn)** → 약한 불에서 오랫동안 푹 끓이는 방법 (국물 요리)

7.  **烧 (shāo)** → 재료를 먼저 볶은 후 간을 하여 중약불에서 익히는 방법

8.  **蒸 (zhēng)** → 수증기로 찌는 방법

9.  **煮 (zhǔ)** → 물이나 육수에 삶거나 끓이는 방법

🥗 차갑게 섞는 조리

10. **拌 (bàn)** → 삶거나 익힌 재료를 양념과 함께 섞는 방법 (무침, 냉채)

# 总称 zǒngchēng 총칭

1️⃣ 中国菜是中国各个地区各种菜的总称。

**Zhōng guó cài shì Zhōng guó gè gè dì qū gè zhǒng cài de zǒng chēng.** → 중국 요리는 중국 각 지역의 여러 요리를 통칭하는 말이다.

2️⃣ 少数民族是除了汉族以外的回族、朝鲜族等55个民族的总称。

**Shǎo shù mín zú shì chú le Hàn zú yǐ wài de Huí zú、Cháo xiǎn zú děng wǔ shí wǔ gè mín zú de zǒng chēng.**

→ 소수민족은 한족을 제외한 회족, 조선족 등 55개 민족을 통칭하는 말이다.

# 课文

- 李大成：张经理，昨天的中国菜真好吃啊！

- 张昆：不错吧？那是浙江菜系的代表才。

- 李大成：浙江菜系？中国菜还有很多种类吗？？我对中国菜很感兴趣，你能简单的介绍一下吗？

- 张昆：当然可以。中国菜是中国各个地区各种菜的**忠诚**，最有名的有八个地方的菜，其中就有浙江菜。中国菜最有代表性的有“四大菜系”：四川菜，山东菜，广东菜和江苏菜。

- 李大成：这么多呀！都有什么特点呢？

- 张昆：中国很大，每个地方的口味都不一样，中国人常说“南甜北咸，东辣西酸”：，比如说，山东菜比较咸，江苏菜就比较甜，四川菜又嘛又辣，广东菜口味清淡，但是他们都有一个共同点：色香味**俱全**。

- 李大成：难怪中国菜又好看又好吃呢！那请朋友吃饭的话要注意什么？

- 张昆：首先要了解餐厅的特点，还要知道一起吃饭的人有没有忌口或者其他的**忌讳**，比如只吃素，不吃猪肉，不吃**海鲜**等等。进餐厅以后一般先点**酒水**，然后点菜。

# 达成 (합의·목표 등을) 이루다, 성사시키다

- 达成目标 **Dá chéng mù biāo**

- 达成交易 **Dá chéng jiāo yì**

- 达成共识 **Dá chéng gòng shí**

1️⃣ 今年上半年我们已经达成业绩目标。

**Jīn nián shàng bàn nián wǒ men yǐ jīng dá chéng yè jì mù biāo.** → 올해 상반기에 우리는 이미 실적 목표를 달성했다.

2️⃣ 我们和客户在合作方面达成共识。

**Wǒ men hé kè hù zài hé zuò fāng miàn dá chéng gòng shí.** → 우리는 고객과 협력 방면에서 합의에 도달했다.

# 达成&达到（目标、水平、程度）

1️⃣ 经过多次谈判，双方最终达成了合作协议。

**Jīng guò duō cì tán pàn, shuāng fāng zuì zhōng dá chéng le hé zuò xié yì.** → 여러 차례 협상 끝에 양측은 최종적으로 협력 협의를 체결했다.

2️⃣ 我们的产品销量达到了预期目标。

**Wǒ men de chǎn pǐn xiāo liàng dá dào le yù qī mù biāo.** → 우리 제품 판매량은 예상 목표에 도달했다.

3️⃣ 只有充分沟通，才能达成一致意见。

**Zhǐ yǒu chōng fèn gōu tōng, cái néng dá chéng yí zhì yì jiàn.** → 충분히 소통해야만 일치된 의견에 도달할 수 있다.

4️⃣ 今年北京夏天的最高气温达到了42度。

**Jīn nián Běi jīng xià tiān de zuì gāo qì wēn dá dào le sì shí èr dù.** → 올해 베이징 여름 최고 기온은 42도에 도달했다.

1️⃣ 这项技术已经达到了世界领先水平。

**Zhè xiàng jì shù yǐ jīng dá dào le shì jiè lǐng xiān shuǐ píng.** 👉 세계 선도 수준에 도달했다 (수준 → 达到)

2️⃣ 我们需要通过努力达成共识。

**Wǒ men xū yào tōng guò nǔ lì dá chéng gòng shí.** 👉 합의를 이루다 (공동 인식 → 达成)

3️⃣ 今年我们公司已经达成/达到了预期的销售目标。

**Jīn nián wǒ men gōng sī yǐ jīng dá chéng / dá dào le yù qī de xiāo shòu mù biāo.**

👉 둘 다 가능하지만 뉘앙스 차이 있음:

- 达成 → 목표를 성취했다 (성과 강조)

- 达到 → 목표 수치에 도달했다 (결과·수치 강조)

4️⃣ 他们为了达成交易，不断调整条件。

**Tā men wèi le dá chéng jiāo yì, bù duàn tiáo zhěng tiáo jiàn.** 👉 거래를 성사시키다 (합의·거래 → 达成)

# 一致 **yí zhì** 일치하다, 같다

- 想法一致 **xiǎng fǎ yí zhì**

- 目标一致 **mù biāo yí zhì**

- 意见一致 **yì jiàn yí zhì**

- 达成一致 **dá chéng yí zhì**

1️⃣ 这方面我们的想法一致。

**Zhè fāng miàn wǒ men de xiǎng fǎ yí zhì.** → 이 부분에서 우리의 생각은 일치한다.

2️⃣ 我们部门同事们的目标是一致的。

**Wǒ men bù mén tóng shì men de mù biāo shì yí zhì de.** → 우리 부서 동료들의 목표는 일치한다.

3️⃣ 我们在这个问题上达成了一致。

**Wǒ men zài zhè ge wèn tí shàng dá chéng le yí zhì.** → 우리는 이 문제에서 합의에 도달했다.

# 遗憾 **yí hàn** 아쉽다, 유감이다 (비교적 공식적, 감정이 조금 더 깊음)

可惜 **kě xī** 👉 아깝다, 아쉽다 (일상적 표현)

1️⃣ 不能去中国工作，我感到很遗憾 / 可惜。

**Bù néng qù Zhōng guó gōng zuò, wǒ gǎn dào hěn yí hàn / kě xī.** → 중국에 가서 일하지 못해 매우 아쉽다.

✔ 둘 다 가능

- 遗憾 → 더 공식적

- 可惜 → 일상적

2️⃣ 同事们都去休假了，我有很多工作不能休假，我觉得很遗憾 / 可惜。

**Tóng shì men dōu qù xiū jià le, wǒ yǒu hěn duō gōng zuò bù néng xiū jià, wǒ jué de hěn yí hàn / kě xī.** → 동료들은 모두 휴가 갔는데, 나는 일이 많아서 휴가를 못 가 아쉽다.

✔ 둘 다 자연스러움

일상 상황 → 可惜 더 자연스러움

3️⃣ 很遗憾，你没有通过这次面试。

**Hěn yí hàn, nǐ méi yǒu tōng guò zhè cì miàn shì.** → 유감스럽게도 당신은 이번 면접에 통과하지 못했습니다.

✔ 공식 상황 → **遗憾**만 사용 (可惜는 부적절)

4️⃣ 我非常遗憾没有抓住那次去国外学习的机会。

**Wǒ fēi cháng yí hàn méi yǒu zhuā zhù nà cì qù guó wài xué xí de jī huì.** → 그 해외 유학 기회를 잡지 못한 것이 매우 아쉽다.

✔ 깊은 후회 느낌 → 遗憾이 더 적절

1️⃣ 她年轻时最大的遗憾是没能去外国旅行。

**Tā nián qīng shí zuì dà de yí hàn shì méi néng qù wài guó lǚ xíng.** → 그녀의 젊은 시절 가장 큰 아쉬움은 해외여행을 가지 못한 것이다.

2️⃣ 我们没能进一步合作，留下了遗憾。

**Wǒ men méi néng jìn yí bù hé zuò, liú xià le yí hàn.** → 우리는 더 협력하지 못해 아쉬움을 남겼다.

# 培训 **péi xùn** 교육하다, 훈련하다 / 교육, 연수

- 培训新职员 **péi xùn xīn zhí yuán**

- 培训机构 **péi xùn jī gòu**

- 业务培训 **yè wù péi xùn**

- 进行培训 **jìn xíng péi xùn**

- 培训班 **péi xùn bān**

- 培训课程 **péi xùn kè chéng**

- 培训师 **péi xùn shī**

1️⃣ 我们公司对新员工进行专业技能培训。

**Wǒ men gōng sī duì xīn yuán gōng jìn xíng zhuān yè jì néng péi xùn.** → 우리 회사는 신입 직원에게 전문 기술 교육을 실시한다.

📌 对 + 사람 + 进行培训

2️⃣ 疫情期间，很多公司都转为线上培训模式。

**Yì qíng qī jiān, hěn duō gōng sī dōu zhuǎn wéi xiàn shàng péi xùn mó shì.** → 팬데믹 기간 동안 많은 회사들이 온라인 교육 방식으로 전환했다.

3️⃣ 培训结束后，每个人都要完成一个考核。

**Péi xùn jié shù hòu, měi gè rén dōu yào wán chéng yí gè kǎo hé.** → 교육이 끝난 후 모두가 평가를 완료해야 한다.

# 对策 **duì cè** 대응책, 대책

- 想对策 **xiǎng duì cè** → 대책을 생각하다

- 商量对策 **shāng liáng duì cè** → 대책을 상의하다

- 有对策 **yǒu duì cè** → 대책이 있다

- 制定对策 **zhì dìng duì cè** → 대책을 수립하다

- 紧急对策 **jǐn jí duì cè** → 긴급 대책

- 有效对策 **yǒu xiào duì cè** → 효과적인 대책

1️⃣ 对客户提出的产品问题，你们有什么对策？

**Duì kè hù tí chū de chǎn pǐn wèn tí, nǐ men yǒu shén me duì cè?** → 고객이 제기한 제품 문제에 대해 어떤 대책이 있습니까?

2️⃣ 和朋友一起商量对策。

**Hé péng yǒu yì qǐ shāng liáng duì cè.** → 친구와 함께 대책을 상의하다.

3️⃣ 我们部门的同事一起开会想对策。

**Wǒ men bù mén de tóng shì yì qǐ kāi huì xiǎng duì cè.** → 우리 부서 동료들이 함께 회의를 열어 대책을 생각한다.

4️⃣ 我们需要尽快制定应对市场变化的对策。

**Wǒ men xū yào jǐn kuài zhì dìng yìng duì shì chǎng biàn huà de duì cè.** → 우리는 시장 변화에 대응할 대책을 빨리 수립해야 한다.

上有政策，下有对策。

**Shàng yǒu zhèng cè, xià yǒu duì cè.**

# 除了 A 以外，还 / 也 B

👉 A 이외에도 B가 있다

👉 A뿐만 아니라 B도 있다

📌 보충 설명 / 나머지 부분 강조

＝ 不仅 A，还 B

1️⃣ 我除了会说汉语以外，还会说英语和日语。

**Wǒ chú le huì shuō Hàn yǔ yǐ wài, hái huì shuō Yīng yǔ hé Rì yǔ.** → 나는 중국어뿐만 아니라 영어와 일본어도 할 줄 안다.

2️⃣ 周末我除了去见朋友以外，还去运动。

**Zhōu mò wǒ chú le qù jiàn péng yǒu yǐ wài, hái qù yùn dòng.** → 주말에 나는 친구를 만나는 것 외에도 운동을 한다.

3️⃣ 我除了学习管理课以外，也学习会议、交际和生活。

**Wǒ chú le xué xí guǎn lǐ kè yǐ wài, yě xué xí huì yì, jiāo jì hé shēng huó.** → 나는 관리 수업뿐만 아니라 회의, 교류, 생활도 배운다.

# 除了 A 以外，都 B

👉 A만 예외이고, 나머지는 모두 B이다

👉 只有 A 不是 B，其他都是 B

📌 특정 대상 하나를 제외하고 전부 해당

1️⃣ 我除了周末以外，平时都上班。

**Wǒ chú le zhōu mò yǐ wài, píng shí dōu shàng bān.** → 나는 주말을 제외하고는 평소에는 모두 출근한다.

2️⃣ 我们办公室除了王主任以外，都是女老师。

**Wǒ men bàn gōng shì chú le Wáng zhǔ rèn yǐ wài, dōu shì nǚ lǎo shī.** → 우리 사무실은 왕 주임을 제외하고 모두 여자 선생님이다.

3️⃣ 除了汉拿山以外，别的山都爬过。

**Chú le Hàn ná shān yǐ wài, bié de shān dōu pá guò.** → 한라산을 제외하고 다른 산은 모두 올라봤다.

# 除了 A 以外，不 / 没 B

👉 A만 있고, B는 없다 👉 A만 예외이고 나머지는 모두 부정 👉 **유일성 강조**

📌 只有 A，(别的)都不 / 没…

1️⃣ 我除了韩国语以外，别的语言都不会。

**Wǒ chú le Hán guó yǔ yǐ wài, bié de yǔ yán dōu bú huì.** → 나는 한국어를 제외한 다른 언어는 모두 할 줄 모른다.

2️⃣ 韩国除了现代汽车公司以外，没有别的汽车公司。

**Hán guó chú le Xiàn dài qì chē gōng sī yǐ wài, méi yǒu bié de qì chē gōng sī.** → 한국에는 현대자동차 회사를 제외하면 다른 자동차 회사가 없다.

3️⃣ 她家的客厅除了电视以外，什么都没有。

**Tā jiā de kè tīng chú le diàn shì yǐ wài, shén me dōu méi yǒu.** → 그녀 집 거실에는 텔레비전을 제외하고는 아무것도 없다.

4️⃣ 除了我以外，谁都不能说我先生的不是。

**Chú le wǒ yǐ wài, shéi dōu bù néng shuō wǒ xiān shēng de bú shì.** → 나를 제외하고는 누구도 우리 남편의 흉을 볼 수 없다.
