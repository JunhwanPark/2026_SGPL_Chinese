# 主食 zhǔshí 주식

1️⃣ 点菜的时候先点凉菜，然后点主食。 **Diǎn cài de shíhou xiān diǎn liángcài, ránhòu diǎn zhǔshí.** 👉 음식을 주문할 때 먼저 찬 요리를 시키고, 그다음에 주식을 주문한다.

2️⃣ 南方人的主食一般是米饭。

**Nánfāng rén de zhǔshí yìbān shì mǐfàn.** 👉 남방 사람들의 주식은 보통 쌀밥이다.

3️⃣ 中国人有时候不吃主食，只吃菜就吃饱了。

**Zhōngguó rén yǒu shíhou bù chī zhǔshí, zhǐ chī cài jiù chī bǎo le.** 👉 중국 사람들은 가끔 주식을 먹지 않고 반찬만 먹어도 배가 부르다.

# 点心 diǎnxin 간식，디저트，스낵류

1️⃣ 点菜的时候最后点点心和水果等等。

**Diǎn cài de shíhou zuìhòu diǎn diǎnxīn hé shuǐguǒ děngděng.** 👉 음식을 주문할 때 마지막에 디저트와 과일 등을 주문한다.

2️⃣ 广东人早上喜欢喝早茶、吃点心。

**Guǎngdōng rén zǎoshang xǐhuan hē zǎochá, chī diǎnxīn.** 👉 광둥 사람들은 아침에 모닝티를 마시고 딤섬을 먹는 것을 좋아한다.

# 搭配 dāpèi 배합，조합하다

1️⃣ 点菜的时候要荤素搭配。

**Diǎn cài de shíhou yào hūn sù dāpèi.** 👉 음식을 주문할 때는 고기와 채소를 균형 있게 조합해야 한다.

2️⃣ 衣服的颜色搭配得不错！

**Yīfu de yánsè dāpèi de búcuò!** 👉 옷 색깔 조합이 꽤 괜찮다!

# 讲究 jiǎngjiu 소중히 하다. 신경을 쓰다. 정교하다

**Zhōngguó rén guònián hěn jiǎngjiu chuántǒng.** 👉 중국 사람들은 설날에 전통을 매우 중요하게 여긴다.

2️⃣ 他是个很讲究的人。

**Tā shì ge hěn jiǎngjiu de rén.** 👉 그는 매우 까다롭고 세심한 사람이다.

# “要不然”，意思是“如果不这样的话”，常用在第2小句的开头，表示从前面的句子推出的结果。口语中也可以使用“要不/不然”。

‘要不然’은 ‘그렇지 않으면’이라는 뜻으로 두 번째 소절의 첫머리에 자주 쓰이며 앞의 문장에서 나온 결과를 나타낸다. 구어체에서는‘要不/不然’도 쓸 수 있다.

1️⃣ 去济州岛的机票可得早点儿买，要不然就买不着了。

**Qù Jìzhōudǎo de jīpiào kě děi zǎodiǎnr mǎi, yàobùrán jiù mǎi bu zháo le.** 👉 제주도행 비행기표는 꼭 좀 일찍 사야 해, 안 그러면 못 살 거야.

2️⃣ 我今天一定要记住这些内容，不然我就不睡觉！

**Wǒ jīntiān yídìng yào jìzhù zhèxiē nèiróng, bùrán wǒ jiù bù shuìjiào!** 👉 오늘 반드시 이 내용을 외울 거야, 아니면 안 잘 거야!

3️⃣ 他一定有急事找你，要不就不会一直给你打电话了。

**Tā yídìng yǒu jíshì zhǎo nǐ, yàobù jiù bú huì yìzhí gěi nǐ dǎ diànhuà le.** 👉 그가 분명히 급한 일이 있는 거야, 아니면 계속 전화하지 않았을 거야.

# “说到……”，常在口语中用于引出下一个话题，或转移到谈论的话题。后面常加一个名词、代词作宾语，表示要谈论的话题。

‘说到…’는 구어체에서 다음 주제를 끌어내거나 이야기하는 주제로 옮길 때 자주 사용된다. 뒤에 명사, 대명사를 목적어로 추가하여 이야기할 주제를 나타낸다.

1️⃣ 说到天气，明天的天气预报你看了吗？

**Shuō dào tiānqì, míngtiān de tiānqì yùbào nǐ kàn le ma?** 👉 날씨 얘기가 나와서 말인데, 내일 일기예보 봤어?

2️⃣ 说到电影，你看过新上映的那部电影了吗？

**Shuō dào diànyǐng, nǐ kàn guo xīn shàngyìng de nà bù diànyǐng le ma?** 👉 영화 얘기가 나와서 말인데, 최근에 개봉한 그 영화 봤어?

3️⃣ 说到新电影，你知道中国现在最火的那部电影吗？

**Shuō dào xīn diànyǐng, nǐ zhīdào Zhōngguó xiànzài zuì huǒ de nà bù diànyǐng ma?**

# 讨论结果

1️⃣ 我们对这个问题基本达成了一致。

**Wǒmen duì zhège wèntí jīběn dáchéng le yízhì.**

우리는 이 문제에 대해 기본적으로 합의에 도달했습니다.

2️⃣ 这个问题今天就说到这儿，下次再继续讨论吧。

**Zhège wèntí jīntiān jiù shuō dào zhèr, xià cì zài jìxù tǎolùn ba.**

이 문제는 오늘은 여기까지 하고, 다음에 다시 계속 논의합시다.

3️⃣ 很遗憾，我们在这个问题上意见没有统一。

**Hěn yíhàn, wǒmen zài zhège wèntí shàng yìjiàn méiyǒu tǒngyī.**

유감스럽게도 우리는 이 문제에 대해 의견이 통일되지 않았습니다.

4️⃣ 对于这个问题，我保留意见。

**Duìyú zhège wèntí, wǒ bǎoliú yìjiàn.**

이 문제에 대해서 저는 의견을 보류하겠습니다.

# 保留 보류하다

- 保留意见 → 의견을 보류하다

- 保留时间 → 시간을 남겨 두다

- 保留证据 → 증거를 보존하다

- 保留权力 → 권리를 유지하다

- 保留方案 → 방안을 남겨 두다

1️⃣ 对这个问题，我保留意见。

**Duì zhège wèntí, wǒ bǎoliú yìjiàn.**

이 문제에 대해 저는 의견을 보류하겠습니다.

2️⃣ 你的建议现在先保留，以后再讨论。

**Nǐ de jiànyì xiànzài xiān bǎoliú, yǐhòu zài tǎolùn.**

당신의 제안은 지금은 일단 보류하고, 나중에 다시 논의합시다.

3️⃣ 对这个问题我们持保留意见（态度）。

**Duì zhège wèntí wǒmen chí bǎoliú yìjiàn (tàidù).**

이 문제에 대해 우리는 유보적인 입장을 취하고 있습니다.

4️⃣ 我们决定保留这项决定，等到下次会议上再做最终确认。

**Wǒmen juédìng bǎoliú zhè xiàng juédìng, děng dào xià cì huìyì shàng zài zuò zuìzhōng quèrèn.**

우리는 이 결정을 일단 유보하고, 다음 회의에서 최종 확인하기로 했습니다.

# 冷淡【형용사】

1️⃣ 사람 태도: 무관심하다 / 차갑다

(≠ 热情 rèqíng 따뜻하다, 친절하다)

① 他对人很冷淡。

**Tā duì rén hěn lěngdàn.** 👉 그는 사람들에게 매우 차갑다.

- 对人 → 사람을 대하는 태도

② 他表面上看起来很冷淡，其实是一个很热情的人。

**Tā biǎomiàn shang kàn qǐlái hěn lěngdàn, qíshí shì yí ge hěn rèqíng de rén.** 👉 그는 겉으로 보면 차가워 보이지만 사실은 매우 따뜻한 사람이다.

③ 他受到非常冷淡的接待。

**Tā shòudào fēicháng lěngdàn de jiēdài.** 👉 그는 매우 냉담한 대접을 받았다.

- 接待 → 접대

- 受到 → 받다

2️⃣ 장사·분위기: 한산하다 / 잘 안 되다

④ 这家餐厅的生意很冷淡。

**Zhè jiā cāntīng de shēngyì hěn lěngdàn.** 👉 이 식당은 장사가 잘 안 된다.

- 生意 → 장사, 사업

- 冷淡 → 손님이 적다, 한산하다

# 接触

1️⃣ 사람·사회적 의미

👉 접촉하다 / 교류하다 / 교제하다

① 在中国工作的时候，您常接触韩国人还是中国人？

**Zài Zhōngguó gōngzuò de shíhou, nín cháng jiēchù Hánguó rén háishi Zhōngguó rén?** 👉 중국에서 일하실 때, 한국인을 더 많이 접촉하셨나요 아니면 중국인을 더 많이 접촉하셨나요?

- 常 → 자주

- 还是 → 선택 질문

② 跟他接触以后，觉得很好相处。

**Gēn tā jiēchù yǐhòu, juéde hěn hǎo xiāngchǔ.** 👉 그와 접촉해 보고 나니 함께 지내기 좋다고 느꼈다.

- 相处 → 함께 지내다

- 接触以后 → 접해 본 후

2️⃣ 물리적 의미

👉 닿다 / 접촉하다 / 맞닿다

③ 孩子应该多接触大自然。

**Háizi yīnggāi duō jiēchù dàzìrán.** 👉 아이들은 자연을 많이 접해야 한다.

- 大自然 → 대자연 (교육·환경 문장에서 자주 사용)

④ 这个产品有接触不良问题。

**Zhège chǎnpǐn yǒu jiēchù bùliáng wèntí.** 👉 이 제품은 접촉 불량 문제가 있다.

- 接触不良 → 접촉 불량 (전자·기계 분야 용어)

# 相处

👉 사람과 사람 사이에서 함께 지내다 / 어울리다

1️⃣ 我跟同事们相处得很好。

**Wǒ gēn tóngshìmen xiāngchǔ de hěn hǎo.** 👉 나는 동료들과 아주 잘 지낸다.

2️⃣ 我孩子和同学们相处得很好。

**Wǒ háizi hé tóngxuémen xiāngchǔ de hěn hǎo.** 👉 우리 아이는 친구들과 잘 지낸다.

3️⃣ 这个人很好相处。

**Zhège rén hěn hǎo xiāngchǔ.** 👉 이 사람은 함께 지내기 쉽다.

4️⃣ 我的上司很难相处。

**Wǒ de shàngsi hěn nán xiāngchǔ.** 👉 우리 상사는 함께 지내기 어렵다.

# 宽厚

1️⃣ 기본 의미

👉 너그럽고 인자하다 👉 관대하고 도량이 넓다

(≠ 严格 yángé 엄격하다)

✅ 对下属很宽厚

**Duì xiàshǔ hěn kuānhòu.** 👉 부하 직원에게 매우 관대하다.

- 下属 → 부하

- 对…很宽厚 → ~에게 관대하다

✅ 上司性格宽厚

**Shàngsi xìnggé kuānhòu.** 👉 상사의 성격이 관대하다.

✅ 宽厚待人

**Kuānhòu dàirén.** 👉 사람을 너그럽게 대하다.

- 待人 → 사람을 대하다

✅ 严以律己，宽以待人

**Yán yǐ lǜ jǐ, kuān yǐ dài rén.** 👉 자신에게는 엄격하고, 남에게는 관대하라.

# 打交道

👉 교류하다 / 상대하다 / 업무적으로 접촉하다 **和 / 跟 + 사람 + 打交道**

1️⃣ 他常常和政府部门的人打交道。

**Tā chángcháng hé zhèngfǔ bùmén de rén dǎ jiāodào.** 👉 그는 자주 정부 부서 사람들과 업무적으로 교류한다.

- 政府部门 → 정부 부서

- 常常 → 자주

2️⃣ 他常常和客户打交道。

**Tā chángcháng hé kèhù dǎ jiāodào.** 👉 그는 자주 고객을 상대한다.

- 客户 → 고객

3️⃣ 我喜欢跟性格好的人打交道。

**Wǒ xǐhuan gēn xìnggé hǎo de rén dǎ jiāodào.** 👉 나는 성격 좋은 사람과 교류하는 걸 좋아한다.

# 相反

👉 서로 반대이다 / 정반대이다 **事物的两个方面互相矛盾、互相排斥** → 사물의 두 측면이 서로 모순되고 배타적이다

1️⃣ 梦想和现实往往会相反。

**Mèngxiǎng hé xiànshí wǎngwǎng huì xiāngfǎn.** 👉 꿈과 현실은 종종 서로 반대가 된다.

- 梦想 → 꿈

- 现实 → 현실

- 往往 → 종종

2️⃣ 太太的性格跟我相反，我很外向，她比较内向。

**Tàitai de xìnggé gēn wǒ xiāngfǎn. Wǒ hěn wàixiàng, tā bǐjiào nèixiàng.** 👉 아내의 성격은 저와 반대입니다. 저는 외향적이고, 그녀는 비교적 내향적입니다.

# 随和

👉 온화하고, 고집부리지 않으며, 잘 어울리는 성격

**和气而不固执己见** → 성격이 온화하고, 자기 주장만 고집하지 않는다

🔎 固执己见 (gù zhí jǐ jiàn)

→ 자신의 의견을 고집하며 바꾸지 않다

1️⃣ 他的性格很随和。

**Tā de xìnggé hěn suíhé.** → 그의 성격은 매우 온화하다.

- 性格 xìnggé = 성격

- 随和 suíhé = 온화하다, 고집이 세지 않다

2️⃣ 张先生待人很随和。

**Zhāng xiānsheng dàirén hěn suíhé.** → 장 선생은 사람을 대하는 태도가 매우 온화하다.

- 待人 dàirén = 사람을 대하다

3️⃣ 要学习随和处事。

**Yào xuéxí suíhé chǔshì.** → 온화하게 처세하는 법을 배워야 한다.

- 处事 chǔshì = 일을 처리하다, 처세하다

# 严肃

**yánsù** → 엄숙하다, 진지하다, 근엄하다

- 表情严肃 biǎoqíng yánsù = 표정이 엄숙하다

- 严肃的场合 yánsù de chǎnghé = 엄숙한 자리

- 严肃对待 yánsù duìdài = 진지하게 대하다

1️⃣ 她是一个很严肃的人。

**Tā shì yí gè hěn yánsù de rén.** → 그녀는 매우 엄숙한 사람이다.

2️⃣ 他做事严肃认真。

**Tā zuòshì yánsù rènzhēn.** → 그는 일을 진지하고 성실하게 한다.

- 做事 zuòshì = 일을 하다

- 认真 rènzhēn = 성실하다, 진지하다

3️⃣ 对高中生父母的问题要严肃对待。

**Duì gāozhōngshēng fùmǔ de wèntí yào yánsù duìdài.** → 고등학생 학부모의 문제는 진지하게 대해야 한다.

- 高中生 gāozhōngshēng = 고등학생

- 父母 fùmǔ = 부모

- 对待 duìdài = 대하다

4️⃣ 我们老板看起来有点严肃，其实他很随和。

**Wǒmen lǎobǎn kàn qǐlái yǒudiǎn yánsù, qíshí tā hěn suíhé.** → 우리 사장은 좀 엄숙해 보이지만 사실은 매우 온화하다.

- 看起来 kàn qǐlái = ~처럼 보이다

- 其实 qíshí = 사실은

- 随和 suíhé = 온화하다, 부드럽다

# 能干

**nénggàn** → 유능하다, 일을 잘하다, 능력이 뛰어나다

1️⃣ 他一个人负责三个部门，他真能干。

**Tā yí gè rén fùzé sān gè bùmén, tā zhēn nénggàn.** → 그는 혼자서 세 개 부서를 책임진다. 정말 유능하다.

- 负责 fùzé = 책임지다

- 部门 bùmén = 부서

- 真 zhēn = 정말

2️⃣ 他太太是个能干的人，上班还一个人带三个孩子。

**Tā tàitai shì gè nénggàn de rén, shàngbān hái yí gè rén dài sān gè háizi.** → 그의 아내는 매우 유능한 사람이다. 직장에 다니면서도 혼자서 세 아이를 돌본다.

- 太太 tàitai = 부인

- 上班 shàngbān = 출근하다, 직장 다니다

- 带孩子 dài háizi = 아이를 돌보다

- 还 hái = 게다가, 또

# 可惜

**kěxī** → 아쉽다, 유감이다, 안타깝다

1️⃣ 这次机会很好，可惜我们错过了。

**Zhè cì jīhuì hěn hǎo, kěxī wǒmen cuòguò le.** → 이번 기회는 정말 좋았는데, 아쉽게도 우리가 놓쳤다.

- 机会 jīhuì = 기회

- 错过 cuòguò = 놓치다

2️⃣ 这个手机慢是慢，但还能用，扔了很可惜。

**Zhège shǒujī màn shì màn, dàn hái néng yòng, rēng le hěn kěxī.** → 이 휴대폰이 느리긴 느리지만 아직 쓸 수 있는데, 버리기엔 아깝다.

- 慢是慢 = 느리긴 느리다 (양보 표현)

- 扔 rēng = 버리다

3️⃣ 算法能预测天气，可惜算不出人类下一次心动的时间。

**Suànfǎ néng yùcè tiānqì, kěxī suàn bu chū rénlèi xià yí cì xīndòng de shíjiān.** → 알고리즘은 날씨를 예측할 수 있지만, 인간이 다음에 설레는 시간을 계산해내지는 못한다.

- 算法 suànfǎ = 알고리즘

- 预测 yùcè = 예측하다

- 算不出 = 계산해낼 수 없다

- 心动 xīndòng = 설레다

# 常用短语

1️⃣ 不仅…而且…

**bùjǐn… érqiě…** → ~뿐만 아니라, 게다가 ~도

2️⃣ 服务周到

**fúwù zhōudào** → 서비스가 세심하다, 배려가 잘 되어 있다

3️⃣ 为您接风

**wèi nín jiēfēng** → (멀리서 온 사람을 위해) 환영 연회를 열다

4️⃣ 就这么定了

**jiù zhème dìng le** → 그럼 그렇게 정합시다 / 그렇게 결정합시다

5️⃣ 盛情邀请

**shèngqíng yāoqǐng** → 극진한 초대, 정중하고 따뜻한 초대

6️⃣ 派车接您

**pài chē jiē nín** → 차량을 보내 모시다

# 重点句型

1️⃣ 这里不仅环境很好，而且服务也很周到。

**Zhèlǐ bùjǐn huánjìng hěn hǎo, érqiě fúwù yě hěn zhōudào.** → 이곳은 환경이 좋을 뿐만 아니라 서비스도 매우 세심합니다.

2️⃣ 明晚为您接风，不知道您方便吗？

**Míng wǎn wèi nín jiēfēng, bù zhīdào nín fāngbiàn ma?** → 내일 저녁에 환영 자리를 마련하려고 하는데, 괜찮으신지요?

3️⃣ 没问题，你们安排吧。

**Méi wèntí, nǐmen ānpái ba.** → 문제 없습니다. 여러분이 정하세요.

4️⃣ 就这么定了，我们五点派车接您。

**Jiù zhème dìng le, wǒmen wǔ diǎn pài chē jiē nín.** → 그럼 그렇게 정합시다. 저희가 5시에 차를 보내 모시겠습니다.

5️⃣ 谢谢你们的盛情邀请。

**Xièxie nǐmen de shèngqíng yāoqǐng.** → 따뜻한 초대에 감사드립니다.

# 熟悉 shú xī [동] 숙지(熟知)하다. 익히 알다. 충분히 알다. 상세히 알다

🔹 对……熟悉 (duì… shúxī)

👉 ~에 익숙하다 / ~을 잘 알다

1️⃣ 他常去中国出差，所以对中国文化很熟悉。

**Tā cháng qù Zhōngguó chūchāi, suǒyǐ duì Zhōngguó wénhuà hěn shúxī.** → 그는 자주 중국에 출장 가기 때문에 중국 문화에 매우 익숙합니다.

2️⃣ 虽然没见过，但经常通话，所以对彼此已经很熟悉了。

**Suīrán méi jiànguò, dàn jīngcháng tōnghuà, suǒyǐ duì bǐcǐ yǐjīng hěn shúxī le.** → 직접 만난 적은 없지만 자주 통화해서 서로 이미 많이 익숙해졌습니다.

3️⃣ 我刚上任，对这里的工作还不熟悉。

**Wǒ gāng shàngrèn, duì zhèlǐ de gōngzuò hái bù shúxī.** → 저는 막 부임해서 이곳 업무에 아직 익숙하지 않습니다.

# 顺利 shùnlì [형] 순조롭다.

👉 일이 막힘없이 잘 진행되다 / 순조롭다

1️⃣ 祝你一切顺利。

**Zhù nǐ yíqiè shùnlì.** → 당신의 모든 일이 순조롭기를 바랍니다.

2️⃣ 祝大家万事顺利！

**Zhù dàjiā wànshì shùnlì!** → 여러분 모든 일이 순조롭기를 바랍니다!

3️⃣ 我们一行五人顺利到达北京。

**Wǒmen yì xíng wǔ rén shùnlì dàodá Běijīng.** → 우리 일행 5명이 베이징에 무사히 도착했습니다.

4️⃣ 我们顺利完成了任务。

**Wǒmen shùnlì wánchéng le rènwù.** → 우리는 임무를 순조롭게 완수했습니다.

5️⃣ 两个公司几年来合作很顺利。

**Liǎng gè gōngsī jǐ nián lái hézuò hěn shùnlì.** → 두 회사는 몇 년간 협력이 매우 순조로웠습니다.

# 支持 zhīchí [동/명] 지지하다. 응원하다.

👉 지지하다 / 후원하다 / 돕다 / 뒷받침하다

1️⃣ 这次活动能取得成功，少不了大家的支持。

**Zhè cì huódòng néng qǔdé chénggōng, shǎo bù liǎo dàjiā de zhīchí.** → 이번 행사가 성공할 수 있었던 것은 여러분의 지원이 있었기 때문입니다.

2️⃣ 虽然留学费用很高，但父母支持孩子去外面开阔眼界。

**Suīrán liúxué fèiyòng hěn gāo, dàn fùmǔ zhīchí háizi qù wàimiàn kāikuò yǎnjiè.** → 유학 비용은 비싸지만, 부모님은 아이가 밖에 나가 견문을 넓히는 것을 지지합니다.

3️⃣ 对……的支持

👉 ~에 대한 지지 / 지원 感谢您对我们的支持和帮助。 **Gǎnxiè nín duì wǒmen de zhīchí hé bāngzhù.** → 저희에 대한 지원과 도움에 감사드립니다.

# 彼此 bǐcǐ [명] 피차. 상호. 쌍방. 서로/피차일반입니다.

**B:** 彼此彼此！ **Bǐcǐ bǐcǐ!** → 저희도 감사합니다! / 서로 협력 덕분입니다!

# 趁 chèn [개] (때, 기회를) 이용해서. 틈타서

👉 “~하는 김에 / ~할 때 얼른”

🔹 趁……的时候

**chèn …… de shíhou** → ~할 때 / ~한 김에

① 趁年轻（的时候），多学习、多赚钱。

**Chèn niánqīng (de shíhou), duō xuéxí, duō zhuànqián.** → 젊을 때 많이 배우고 많이 벌어라.

② 趁年假（的时候）回老家一趟。

**Chèn niánjià (de shíhou) huí lǎojiā yí tàng.** → 연차 휴가일 때 고향에 한 번 다녀오세요.

③ 趁热（的时候）多吃点！

**Chèn rè (de shíhou) duō chī diǎn!** → 따뜻할 때 많이 먹어!

🔹 趁……的机会

**chèn …… de jīhuì** → ~의 기회를 빌려 / 이 기회에

④ 趁这次机会，好好儿休息休息。

**Chèn zhè cì jīhuì, hǎohāor xiūxi xiūxi.** → 이번 기회에 푹 쉬세요.

# 口味（儿） kǒu wèi(r) [명] 맛. 구미. 기호

🔹 什么口味

**shénme kǒuwèi** → 어떤 맛 / 어떤 취향

① 你喜欢吃什么口味的冰激凌？

**Nǐ xǐhuān chī shénme kǒuwèi de bīngjīlíng?** → 어떤 맛 아이스크림을 좋아하세요?

🔹 合口味

**hé kǒuwèi** → 입맛에 맞다

② 四川菜比较辣，不知道合不合您的口味？

**Sìchuān cài bǐjiào là, bù zhīdào hé bu hé nín de kǒuwèi?** → 쓰촨 음식은 비교적 매운데, 입맛에 맞을지 모르겠습니다.

# 美食家 měishíjiā [명]미식가

1️⃣ 张总可是个美食家。

**Zhāng zǒng kě shì ge měishíjiā.** → 장 사장님은 정말 미식가예요.

2️⃣ 我的爱好是去各地的米其林餐厅品尝美食，他们都叫我美食家。

**Wǒ de àihào shì qù gèdì de Mǐqílín cāntīng pǐncháng měishí. Tāmen dōu jiào wǒ měishíjiā.** → 제 취미는 각 지역의 미슐랭 레스토랑에 가서 음식을 맛보는 것입니다. 그들은 저를 모두 미식가라고 불러요.

# 丰盛 fēnɡ shènɡ [형] 풍부하다. 풍성하다.

1️⃣ 谢谢你们准备了这么丰盛的晚餐。

**Xièxie nǐmen zhǔnbèi le zhème fēngshèng de wǎncān.** → 이렇게 풍성한 저녁 식사를 준비해 주셔서 감사합니다.

2️⃣ 今天晚上的菜太丰盛了！

**Jīntiān wǎnshang de cài tài fēngshèng le!** → 오늘 저녁 음식이 정말 너무 푸짐해요!

# 提议 tíyì [동/명] 제의(하다)

1️⃣ 大家都同意这个提议吗？

**Dàjiā dōu tóngyì zhège tíyì ma?** → 모두 이 제안에 동의합니까?

2️⃣ 你的这个提议不错。

**Nǐ de zhège tíyì búcuò.** → 당신의 이 제안은 괜찮습니다.

3️⃣ 我提议为我们合作愉快干杯！

**Wǒ tíyì wèi wǒmen hézuò yúkuài gānbēi!** → 우리의 즐거운 협력을 위해 건배를 제안합니다!
