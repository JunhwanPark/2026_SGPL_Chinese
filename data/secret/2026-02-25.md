# 选词填空

1️⃣ 孩子应该多接触大自然。

**Háizi yīnggāi duō jiēchù dàzìrán.** → 아이는 자연을 많이 접해야 한다.

- 接触 jiēchù = 접촉하다, 접하다

- 大自然 dàzìrán = 자연

2️⃣ 节假日期间各地景点可能有很多人。

**Jiéjiàrì qījiān gèdì jǐngdiǎn kěnéng yǒu hěn duō rén.** → 명절·휴일 기간에는 각지의 관광지에 사람이 많을 수 있다.

- 节假日 jiéjiàrì = 공휴일

- 期间 qījiān = ~기간 동안

- 景点 jǐngdiǎn = 관광지

- 各地 gèdì = 각 지역

3️⃣ 她是一个很好相处的人。

**Tā shì yí gè hěn hǎo xiāngchǔ de rén.** → 그녀는 아주 함께 지내기 쉬운 사람이다.

- 相处 xiāngchǔ = 함께 지내다

- 好相处 = 성격이 좋고 편하다

4️⃣ 他是一个对自己宽厚，对别人严格的人。

**Tā shì yí gè duì zìjǐ kuānhòu, duì biérén yángé de rén.** → 그는 자신에게는 관대하고, 남에게는 엄격한 사람이다.

- 宽厚 kuānhòu = 너그럽다

- 严格 yángé = 엄격하다

5️⃣ 我喜欢跟性格好的人打交道。

**Wǒ xǐhuān gēn xìnggé hǎo de rén dǎ jiāodào.** → 나는 성격 좋은 사람과 교류하는 걸 좋아한다.

- 打交道 dǎ jiāodào = 거래하다, 교류하다, 상대하다

6️⃣ 他一个人负责三个部门，他真能干。

**Tā yí gè rén fùzé sān gè bùmén, tā zhēn nénggàn.** → 그는 혼자서 세 개 부서를 담당한다. 정말 유능하다.

- 负责 fùzé = 책임지다

- 能干 nénggàn = 능력이 뛰어나다

7️⃣ 这个手机慢是慢，还能用，扔了太可惜了。

**Zhège shǒujī màn shì màn, hái néng yòng, rēng le tài kěxī le.** → 이 휴대폰은 느리긴 느리지만 아직 쓸 수 있는데, 버리기엔 너무 아깝다.

- 慢是慢 = 느리긴 느리다 (양보 구조)

- 扔 rēng = 버리다

- 太可惜了 = 너무 아깝다

# 确实 确定实际；确切信实（副）对客观情况的真实性表示肯定；表示情况符合实际。

**Niánjì dàle xuéxí wàiyǔ quèshí bù qīngsōng.**

→ 나이가 들어 외국어를 배우는 것은 확실히 쉽지 않습니다.

•公司的管理确实有很多问题。

**Gōngsī de guǎnlǐ quèshí yǒu hěnduō wèntí.**

→ 회사의 관리에 확실히 문제가 많습니다.

•今年夏天确实很热。

**Jīnnián xiàtiān quèshí hěn rè.**

→ 올여름은 정말 덥네요.

# 课文 - 白酒

- 李大成：张部长，我想买点中国白酒，你一般在哪儿买酒？

- 张和平：你是自己和还是送人？

- 李大成：下周有个韩国朋友来中国，我想跟他一起喝。

- 张和平：中国酒的种类太多了，价格差距也很大，十大名酒你听说过吗？

- 李大成：我只知道水井坊和茅台，还有什么酒？

- 张和平：水井坊可不是十大名酒，十大名酒有茅台，五粮液，西凤酒，古井贡酒等等。

- 李大成：最近很多韩国人喜欢五粮液。

- 张和平：五粮液使用五重粮食做的，所以叫五粮液。你喝过吗？

- 李大成：没喝过，我想尝尝五粮液。在哪儿买？

- 张和平：你可以在网上买也可以去超市买，我经常在京东买，有活动的时候能便宜点儿，而且质量也有保障。

- 李大成：五粮液多少度？

- 张和平：低度五粮液有39度，经典的是52度，一般人都买52度的。

- 李大成：那我就买52度的吧。一般多少钱一瓶？

- 张和平：1000多，好喝是好喝，就是有点儿贵。

- 李大成：没关系，作为一个爱喝酒的人，我觉得这个价格还可以。

- 张和平：喝酒的时候一定要叫上我。
